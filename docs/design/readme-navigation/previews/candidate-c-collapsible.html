Nigeria PAYE, VAT, WHT, CIT, CGT & 9 more tax calculators, as static PHP method calls — no API key, no Guzzle, no account.

use TaxLane\TaxLane;

TaxLane::calculatePaye(['grossAnnualIncome' => 6_000_000])['data'];
// ['taxableIncome' => 6000000, 'payeTax' => 870000, 'monthlyTax' => 72500, ...]

Install

composer require quineworks/taxlane

Quickstart

$response = TaxLane::calculatePaye([
    'grossAnnualIncome' => 6_000_000,
    'annualRentPaid' => 1_200_000,
]);
$response['data'];
$response['rateLimit'];

Endpoints

calculatePaye — PAYE on an employee's gross annual income 
TaxLane::calculatePaye(['grossAnnualIncome' => 6_000_000])['data'];
// ['taxableIncome' => 6000000, 'payeTax' => 870000, ...]

Only grossAnnualIncome is required — every other field defaults to 0.

calculatePayrollBatch — PAYE for up to 1,000 employees in one call 
TaxLane::calculatePayrollBatch(['employees' => [...]])['data'];
calculateVat — VAT on an amount, inclusive or exclusive 
TaxLane::calculateVat(['amount' => 100_000, 'mode' => 'exclusive'])['data'];

calculatePensionContribution — Pension contribution + balance projection 
TaxLane::calculatePensionContribution(['annualBasicSalary' => 3_000_000])['data'];

Response shape

Every method returns ['data' => ..., 'rateLimit' => ...], a plain associative array.

Errors

Throws TaxLane\TaxLaneApiException on a non-200 response.

Rate limits

Parsed from X-RateLimit-* headers on every response.

Limits

No API key, no daily cap — 50 req/s shared Gateway ceiling.

Published to Packagist as quineworks/taxlane.
